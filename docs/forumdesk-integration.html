ForumDesk 网页客服接入

浏览器只访问 New API 同域接口；New API 后端代理 Tailscale 内网的 ForumDesk。API Key 与 visitor_token 不进入前端、Git、日志或接口响应。

环境变量 登录态接口 部署 数据库 错误码 回滚

架构

Browser (HTTPS)
  → POST/GET /api/support/*   （当前站点同域，登录态）
    → New API 后端
      → ForumDesk  http://100.64.0.2:8980
         Authorization: Bearer API_KEY | visitor_token

先调用 GET /healthz 验证连通性。连接超时 3s，总超时 10s。上游 429 不重试，透传 Retry-After。

环境变量

密钥只放后端环境变量。下面复制的是变量名和占位写法，不要把真实密钥提交到 Git。

FORUMDESK_API_BASE=http://100.64.0.2:8980
FORUMDESK_API_KEY=your-forumdesk-api-key
# /root/newapi/.env（已被 .gitignore）
FORUMDESK_API_BASE=http://100.64.0.2:8980
FORUMDESK_API_KEY=your-forumdesk-api-key

登录态接口

方法路径说明
POST /api/support/conversations 创建或复用当前用户客服会话。请求体 {"page_url":"..."}。响应只含 conversation_id。
POST /api/support/conversations/:id/messages 发送消息 {"text":"...","reply_to_message_id":"wm_..."}。引用字段可选。
GET /api/support/conversations/:id/messages?after=&limit=50 增量拉取。保存 data.next_cursor，前端每 2 秒轮询。处理 event=message_hidden。

三个接口均需 UserAuth。服务端校验 conversation 归属当前用户；visitor_token 只存在服务端。

部署命令

curl -sS http://100.64.0.2:8980/healthz
cd /root/newapi && docker compose up -d --build newapi
curl -sS http://127.0.0.1:3000/api/status
cd /root/newapi && go test ./service ./controller ./model -count=1 -timeout 120s
cd /root/newapi/web && bun run test src/features/support

数据库变更

GORM AutoMigrate 新增表 forum_desk_sessions：

id, user_id (unique), conversation_id (unique), visitor_token, created_at, updated_at

visitor_token 带 json:"-"，接口响应不会带出。
