快速开始

三步完成接入。

  1. 登录控制台后进入「令牌管理」，创建并复制 API Key。Key 只展示一次
  2. 在客户端中将 Base URL 设置为 https://api.tuftech.org.
  3. 按客户端类型选择接口路径：OpenAI 兼容用 /v1/chat/completions 或 /v1/responses，Claude 兼容用 /v1/messages。
curl https://api.tuftech.org/v1/chat/completions \
  -H "Authorization: Bearer $TUFTECH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
请妥善保管令牌，不要放进公开仓库、网页前端或聊天截图。Key 一旦泄露请立即在控制台禁用并重建。

频率限制

限流按单个用户账号统计，同一用户下多个 API Key 共享额度，不同用户互不影响。

  • 平台默认：每 1 分钟最多 120 次请求、100 次成功请求。
  • 各分组可覆盖默认值，具体见上方「分组与倍率」表的限流列（例如 veo 明显更低，用于控制高成本任务）。
  • 触发限流会返回 429，稍后重试即可。

如何开始使用 TUFTech API？
登录后进入「令牌管理」创建 API Key。客户端 Base URL 填 https://api.tuftech.org；OpenAI 兼容客户端一般使用 /v1/chat/completions 或 /v1/responses，Claude 兼容客户端使用 /v1/messages。API Key 只展示一次，请不要放进公开仓库、网页前端或聊天截图。
我应该选择哪个分组？
Codex / OpenAI 编程场景优先看 codex-pro、codex-plus；Claude Code / Anthropic 场景看 cc-max、cc-max-chat、cc-aws-p、aws-kiro；Gemini 场景用 gemini-ultra；视频生成用 veo。不同分组对应不同可用模型、速度和稳定性。
模型价格怎么看？
模型广场展示平台模型基础价格；token 模型通常按输入、输出、缓存读写分别计价，视频模型按次计价。实际扣费还会叠加令牌所选分组倍率。当前主要分组倍率：codex-plus 0.4x，codex-pro 0.7x，aws-kiro 0.7x，gemini-ultra 1x，cc-max 2.6x，cc-max-chat 1.3x，veo 1.3x，cc-aws-p 5.2x。使用日志展示每次调用的实际扣费，是核对账单的主要依据。
gpt-5.5 如何计费？
gpt-5.5 已按模型广场价格补齐：输入 $5 / 1M tokens、输出 $30 / 1M tokens、缓存读 $0.5 / 1M tokens。最终以控制台价格页和使用日志为准。
Veo 视频模型怎么用、怎么计费？
Veo 分组包含 veo_3_1、veo_3_1-fast-fl、veo_3_1-fast-fl-hd。视频模型按次计费，当前单次价格分别为 $2.5、$0.8、$1.6。提交任务后会返回 task_id，使用 /v1/videos/{task_id} 轮询状态；失败或取消任务按平台逻辑退款。
频率限制是按用户还是全平台？
模型请求限流按单个用户账号统计，同一用户下多个 API Key 共享限流；不同用户互不影响。默认限制是每 1 分钟最多 120 次请求、100 次成功请求；分组可覆盖这个默认值，例如 veo 分组更低，适合控制高成本任务。
注册送额度和邀请奖励是多少？
新用户注册成功后赠送 8.88 额度；通过邀请关系注册时，邀请人和被邀请人各赠送 5 额度。奖励是否到账可在账户余额、日志或邀请记录中核对。
调用失败时怎么排查？
先看使用日志：确认模型名、分组、状态码、错误信息、请求时间和扣费记录。401 多为 Key 错误或令牌禁用；402 是余额不足；429 是触发限流；503 通常表示对应渠道暂无可用账号或上游不可用。请带上日志截图或关键信息联系管理员：邮箱 musk@paipaiio.com，Telegram @tuf_tech。
邮箱验证、隐私政策和用户协议有什么影响？
本站已开启邮箱验证，并启用隐私政策和用户协议。注册、登录、额度、日志和模型转发会按页面说明处理。调用模型时，请不要提交与使用目的无关的敏感个人信息、商业秘密或未经授权的数据。
